Test pages

Every page in the School Compliance Toolkit, including the ones not released yet, so you can look through and test each one. This page isn't linked from the home page.

Test data: download the demo DfE standards file (a fictional school with every standard filled in), then use Import Excel in the DfE tracker. Importing replaces what's in the tracker in this browser. To start again from nothing, use Clear all data at the bottom of the home page.
Pages marked Coming soon are greyed out on the home page and show a "Preview" label when opened from here. To release one, remove it from the list at the top of docs/features.js.
